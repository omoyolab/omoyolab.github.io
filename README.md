# omoyolab.github.io

Forwards old GitHub Pages addresses to where the projects live now.

| Old address                              | New address                                          |
| ---------------------------------------- | ---------------------------------------------------- |
| `omoyolab.github.io/afrigov/…`           | [afrigov.dev](https://afrigov.dev)                   |
| `omoyolab.github.io/afrigov-usecases/…`  | [usecases.afrigov.dev](https://usecases.afrigov.dev) |

GitHub Pages has no server-side redirects, so `404.html` does it: any missing
page under a moved path is sent to the same path on the new site.
